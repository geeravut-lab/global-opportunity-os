# ขั้นตอนถัดไปสำหรับเจ้าของโครงการ

อัปเดตวันที่ 2026-11-04: เจ้าของเลือกตามข้อแนะนำทั้ง 4 เรื่องแล้ว
บันทึกการอนุมัติและขอบเขตใน LEG-C-07/LEG-C-08 และเลือก Vercel ใน LEG-C-09 ไม่ต้องถามเลือกซ้ำ

## สถานะและลำดับงาน

มี **6 ระยะ นับ Phase 0–5**

| ระยะ | ผลงาน | สถานะ |
| --- | --- | --- |
| Phase 0 | แผนและทะเบียนข้อยืนยัน/ข้อเสนอ | ยอมรับฐานชั่วคราว S0-*; นิยาม REQ/AC ต้นฉบับยังไม่มี จึงไม่อ้างว่าผ่านนิยามเหล่านั้น |
| Phase 1 | โครง Next.js + React + TypeScript + npm คำสั่งจริงและ CI | อนุมัติแล้วและสร้างในสาขาชิ้นงานปัจจุบัน |
| Phase 2 | ไดเรกทอรีไทย–อังกฤษ ข้อมูลสมมติ สถานะและตัวกรอง | อนุมัติแล้ว มีชิ้นงานสำหรับทบทวน ดูผลตรวจและข้อจำกัดใน IMPLEMENTATION_REPORT.md |
| Phase 3 | Navigator | ยังไม่อนุมัติ |
| Phase 4 | ส่งต่อ/เคส สิทธิ์ตามองค์กร และความยินยอม | ยังไม่อนุมัติ ไม่มีฐานข้อมูลหรือข้อมูลส่วนบุคคลจริง |
| Phase 5 | ผลลัพธ์เบื้องต้นจากข้อมูลรวม | ยังไม่อนุมัติ |

## สิ่งที่คุณต้องทำต่อ

1. ทบทวนชิ้นงานและ [ผลตรวจ](IMPLEMENTATION_REPORT.md) โดยเฉพาะภาษาไทย/อังกฤษและสถานะตัวอย่าง
2. ตรวจหน้าตาด้วยคน การซูม 200% โปรแกรมอ่านหน้าจอ ลำดับ/การมองเห็นโฟกัส และคุณภาพคำแปลก่อนถือว่า LEG-G-03 ครบ
3. ตรวจค่าของ Vercel Project เดิมตาม [คู่มือ](VERCEL.md) โดยเฉพาะ production branch และ deployment อัตโนมัติ
4. เมื่อพอใจ ระบุว่าจะให้บันทึก/ส่งสาขาขึ้น GitHub และอนุญาต Preview deployment หรือไม่ โดยยังไม่ merge/deploy production ถ้าไม่ได้อนุมัติ

งานในเครื่องไม่เท่ากับ deployment ที่สำเร็จ ไม่ได้ตรวจ integration จริง และ CI ที่เตรียมไว้ยังไม่รันบน GitHub
ยังไม่ขยายไป Phase 3–5 หรือรับข้อมูลจริง การเลือกเทคโนโลยีไม่ได้อนุมัติ schema/กฎหมาย/พันธมิตรระยะหลัง

## นำบริบทไปยัง Project เดิม

หากเป็นแชตใน ChatGPT และมีเมนู `⋯` → **Move to project / ย้ายไปยังโปรเจกต์**
ให้เลือก Project เดิมและตรวจว่าบทสนทนาปรากฏอยู่จริง เมนูขึ้นกับผลิตภัณฑ์และบัญชี
เซสชันนี้ไม่มีเครื่องมือย้ายบทสนทนาและไม่ได้ย้ายให้โดยอัตโนมัติ

หากเป็นงาน Codex หรือไม่มีเมนูย้าย ให้เปิดแชตใน Project ปลายทาง แนบเอกสารตาม docs/INDEX.md
และส่งบริบทด้านล่าง การเลือก repository เดียวกันไม่ย้ายประวัติแชต และการเผยแพร่ cloud environment
ไม่ใช่การ commit/push ไฟล์ ปัจจุบันใช้สาขา `feat/bilingual-demo-directory` ซึ่งยังมีงานที่ไม่ได้ commit/push
ต้องส่งไฟล์โดยตรงหรือบันทึกเข้า Git/ส่งสาขาตามขั้นตอนที่อนุญาตก่อนเปิดงานใหม่จาก GitHub

ข้อความส่งต่อ:

> Global Opportunity OS สื่อสารและเขียนเอกสารเป็นภาษาไทย อ่าน README.md และ docs/INDEX.md ทั้งหมด
> เจ้าของอนุมัติเฉพาะ Phase 1–2: ไดเรกทอรีไทย–อังกฤษ ข้อมูลสมมติ ใช้ Next.js/React/TypeScript/npm
> ยอมรับ S0-01 ถึง S0-09 เป็นฐานชั่วคราว ไม่แต่งนิยาม REQ/AC ที่ขาด
> เลือก Vercel และแจ้งว่าเชื่อม GitHub แล้ว แต่ยังไม่อนุมัติ push/deploy production
> อ่าน docs/DECISIONS.md และ docs/IMPLEMENTATION_REPORT.md ตรวจไฟล์/สถานะ Git ก่อนเปลี่ยน
