# เมนูมือถือที่กำลังเปิดอยู่ — C-37

เจ้าของขอให้ bottom bar แสดงหน้าปัจจุบัน ถ้าหน้าอยู่ในเพิ่มเติมให้เน้นเพิ่มเติม และเมื่อเปิดแผงให้แสดงรายการที่เลือกพร้อมเลื่อนให้เห็น

- ปุ่ม/ลิงก์ปัจจุบันใช้สีหลัก Opp4All พื้นหลังอ่อน น้ำหนักตัวหนา และขีดเน้น ไม่อาศัยสีเพียงอย่างเดียว
- ลิงก์ใช้ `aria-current="page"`; ปุ่มเพิ่มเติมใช้ `aria-current="true"` เมื่อเมนูปัจจุบันอยู่หลังสี่รายการแรก การเปิดแผงอย่างเดียวไม่เปลี่ยนว่าหน้าใดถูกเลือก
- เมื่อเปิดแผง วัดตำแหน่งภายใน scroller แล้วเลื่อนให้รายการปัจจุบันอยู่ในพื้นที่ที่เห็น โดยไม่เลื่อนหน้าเว็บด้านหลัง
- หน้ารายละเอียดยึดเมนูแม่ที่ตรงที่สุด เช่น ใบสมัคร → ใบสมัคร, แก้ catalog → catalog และ receipt ลบข้อมูล → privacy รวมถึงหน้า policy/purge/reporting ของผู้ดูแล
- คง native dialog/focus trap/Escape/ปุ่มปิด/browser Back/คืน focus และ bottom bar เดิม ไม่เพิ่มสิทธิ์จากการไฮไลต์
